# RC Active Suspension — обновления

Этот публичный репозиторий хранит готовые файлы обновлений приложения и контроллера. Исходный код, ключ подписи APK и пароли сюда не загружаются.


Ветки проекта: [1.8.10 — прошивка](https://github.com/ValeriiLeenet/esp32-drive-firmware/tree/1.8.10) и [1.8.21 — приложение](https://github.com/ValeriiLeenet/esp32-drive-firmware/tree/1.8.21). В каждой есть CHANNEL.md с правилами выпуска. Ветки служат для организации проекта; файлы для обновления приложение получает из Releases.

Приложение проверяет [GitHub Releases](https://github.com/ValeriiLeenet/esp32-drive-firmware/releases) через [GitHub API](https://api.github.com/repos/ValeriiLeenet/esp32-drive-firmware/releases/latest). Версии приложения и прошивки независимы: если последний выпуск содержит только один тип файла, приложение ищет другой среди предыдущих выпусков.

## Обновление приложения

Соберите подписанный APK прежним ключом. Имя файла для версии 1.8.21: `RC_Active_Suspension_1_8_21_update.apk`. Создайте обычный GitHub Release с тегом `app-v1.8.21` и прикрепите этот APK как asset. Для следующих версий меняйте номер в теге и имени файла. Приложение сверяет версию, размер и SHA-256 файла из GitHub API перед установкой.

APK, установленный через Google Play, обновляется через Google Play. Для него публикуйте AAB отдельно в Play Console.

## Обновление прошивки

Выпуск 1.8.10 уже содержит `firmware.bin`. Для новой версии создайте обычный Release с тегом `fw-v1.8.11` и приложите OTA-образ `firmware.bin` для ESP32 DevKit V1. Это должен быть образ приложения ESP32, а не полный дамп flash. Можно также назвать файл `TRX4_Active_Suspension_1_8_11.bin`. Перед передачей по Bluetooth приложение проверяет размер, SHA-256 и заголовок образа.

Не заменяйте уже опубликованные файлы задним числом: создавайте новый выпуск. Перед продажей испытайте обновление на резервном контроллере с постоянным питанием.

На 20 октября 2026 опубликована только прошивка 1.8.10. APK появится здесь после сборки и загрузки подписанного файла.
