# Канал прошивки 1.8.10

Эта ветка относится к прошивке контроллера ESP32. Готовый OTA-образ версии 1.8.10 опубликован в [GitHub Release v1.8.10](https://github.com/ValeriiLeenet/esp32-drive-firmware/releases/tag/v1.8.10) как `firmware.bin`.

Приложение скачивает образ из GitHub Releases через API, проверяет размер и SHA-256, затем передаёт его контроллеру по Bluetooth. Сам файл прошивки хранится в релизе, а не в истории Git. Для следующих версий создавайте отдельный релиз с тегом `fw-v1.8.11`, `fw-v1.8.12` и так далее, прикрепляя проверенный OTA-образ `firmware.bin`. Прежде чем опубликовать новый релиз, проверьте прошивку на резервной плате.
