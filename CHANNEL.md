# Канал приложения 1.8.21

Эта ветка относится к Android-приложению RC Active Suspension 1.8.21. Исходники выпуска подготовлены локально; подписанный APK нужно собрать прежним ключом, чтобы он установился поверх предыдущей версии.

Готовый APK публикуется как asset отдельного GitHub Release с тегом `app-v1.8.21`. При создании выпуска выберите ветку `1.8.21` в поле Target и прикрепите файл с точным именем `RC_Active_Suspension_1_8_21_update.apk`. Приложение на телефоне проверяет новые релизы через GitHub API, сверяет размер и SHA-256 APK и открывает системный установщик. Для Google Play отдельно публикуется AAB через Play Console.

Пока APK 1.8.21 не собран и не прикреплён к релизу, этот канал не может предлагать обновление. Ключ подписи, пароли и конфигурацию с секретами в GitHub не загружайте.
