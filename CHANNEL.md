# Канал прошивки 1.8.10

Эта ветка относится к прошивке контроллера ESP32. Готовый OTA-образ версии 1.8.10 опубликован в [GitHub Release v1.8.10](https://github.com/ValeriiLeenet/esp32-drive-firmware/releases/tag/v1.8.10) как `firmware.bin`.

Приложение скачивает образ из GitHub Releases через API, проверяет размер и SHA-256, затем передаёт его контроллеру по Bluetooth. Сам файл прошивки хранится в релизе, а не в истории Git. Существующий выпуск v1.8.10 уже работает независимо от того, что его тег был создан до этой ветки.

Для следующей версии создайте отдельный релиз с тегом `fw-v1.8.11`, выбрав ветку `1.8.10` в поле Target, и прикрепите проверенный OTA-образ `firmware.bin`. Дальше увеличивайте номер версии и создавайте новый релиз для каждого обновления. Прежде чем опубликовать новый релиз, проверьте прошивку на резервной плате.
